## Dataset

Real photographs from the public Kaggle dataset
**["Animal Image Dataset — 90 Different Animals"](https://www.kaggle.com/datasets/iamsouravbanerjee/animal-image-dataset-90-different-animals)**
by Sourav Banerjee. The `deer` and `antelope` classes were extracted to form
this binary classification task. **No synthetic or AI-generated images were used.**

## How the Model Was Built

1. **Data preparation** — real images split 70% train / 15% validation / 15% test,
   resized to 224×224, loaded with `tf.data` pipelines.
2. **Augmentation** — random flip, rotation, zoom, and contrast during training.
3. **Model** — MobileNetV2 (ImageNet weights) as a frozen feature extractor +
   custom dense classification head, then fine-tuned on the top layers at a
   low learning rate.
4. **Evaluation** — accuracy, precision, recall, F1-score, confusion matrix,
   and ROC-AUC on a held-out real test set.
5. **Export** — final model saved as `deer_antelope_model.keras`.

Full, runnable code for every step is in
`GET324_Deer_vs_Antelope_MiniProject.ipynb` (designed for Google Colab with a
GPU runtime).

## Running the App Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Make sure `deer_antelope_model.keras` and `class_names.json` (produced by the
notebook) are in the same folder as `app.py`.

## Deploying to Streamlit Community Cloud

1. Push this repository (including the trained model file) to GitHub.
2. Go to https://share.streamlit.io, sign in with GitHub.
3. Click **New app** → select this repo/branch → set main file to `app.py`.
4. Click **Deploy**. Streamlit installs `requirements.txt` and launches the app.
5. Share the resulting public URL (e.g. `https://<app-name>.streamlit.app`).

## How to Use the App

1. Open the deployed app URL (or run it locally).
2. Upload a `.jpg`, `.jpeg`, or `.png` photo of a deer or an antelope.
3. The app displays the predicted class and its confidence score.
